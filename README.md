# 📊 Automated Management Systems | Google Workspace & Data Analytics

Este repositório centraliza soluções desenvolvidas para otimizar fluxos de trabalho, automatizar processos operacionais e gerar inteligência de dados utilizando o ecossistema Google Cloud.

## 🚀 Visão Geral
O projeto principal consiste em um **Sistema de Gestão de Vendas e Retenção de Clientes** desenvolvido para suprir necessidades de monitoramento em tempo real e automação de tarefas manuais. A solução foca na transformação de planilhas estáticas em ferramentas dinâmicas de tomada de decisão.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem Principal:** Google Apps Script (JavaScript) para automação de workflows.
* **Armazenamento e Estrutura:** Google Sheets atuando como banco de dados ágil.
* **Visualização de Dados:** Gerando um link para visualização do relatório
* **Conhecimentos Integrados:** Aplicação de lógica em Python e consultas SQL para estruturação de dados.

## 🌟 Funcionalidades de Destaque
* **Automação de Retenção:** Algoritmos para rastreamento automático de status de clientes e alertas de churn.
* **Gestão de Vendas:** Dashboard integrado para acompanhamento de metas e performance de vendas.
* **Sincronização de Dados:** Scripts de atualização automática que garantem a integridade das informações entre diferentes fontes de dados.

## 📈 Impacto e Resultados
* **Otimização de Processos:** Redução de tempo em tarefas manuais através de scripts personalizados.
* **Relevância Profissional:** O desenvolvimento dessas soluções e o compartilhamento de aprendizados geraram métricas de engajamento significativas, alcançando mais de **13.000 impressões no LinkedIn**.
* **Suporte Estratégico:** Fornecimento de insights baseados em dados para áreas de atendimento e retenção.
